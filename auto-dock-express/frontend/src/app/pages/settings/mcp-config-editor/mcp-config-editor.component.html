MCP Server Configuration

Configure MCP servers using the Claude Desktop configuration format. Each server requires a command, args array, and optional environment variables.

Configuration Format

{{ '{' }}
  "mcpServers": {{ '{' }}
    "server-name": {{ '{' }}
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "http://localhost:3000/mcp",
        "--header",
        "api-key:YOUR_API_KEY",
        "--header",
        "Authorization:Bearer YOUR_TOKEN"
      ],
      "env": {{ '{' }}
        "AUTH_TOKEN": "Bearer YOUR_TOKEN"
      {{ '}' }}
    {{ '}' }}
  {{ '}' }}
{{ '}' }}

Notes:

  • command: The command to run (e.g., "npx", "node")
  • args: Array of arguments including the MCP server URL and headers
  • --header: Use to pass headers in format "key:value"
  • env: Optional environment variables that can be referenced in args using ${{ '{' }}VAR_NAME{{ '}' }}
  • Headers are extracted and sent to the backend for MCP server communication
